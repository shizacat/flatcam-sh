# Installation instructions

Works with Python version 3.11 or greater and PyQt6.

## Prerequisites

- [Miniforge](https://github.com/conda-forge/miniforge) - A conda-forge distribution.
- [mamba/conda](https://conda-forge.org/download/) - Alternative for miniforge.

## Running from Sources (any operating system)

1. Git clone the project

```bash
git clone ...
```

2. Create a mamba/conda environment

```bash
# Linux
mamba env create -f environment.yml
# macOS
~/miniforge3/bin/mamba env create -f environment.yml
```

3. Activate the environment

```bash
# Linux
mamba activate flatcam
# macOS
eval "$(~/miniforge3/bin/mamba shell hook --shell zsh)"
mamba activate flatcam
```

4. Launch FlatCAM

```bash
cd source
python flatcam.py
```

## Developer mode

A normal launch sends Python exceptions to a dialog and `~/.FlatCAM/log.txt`. A native crash (segfault) produces no traceback.

After `mamba activate flatcam`, from the repository root:

```bash
./dev.sh
```

Traces go to stderr and to `tmp/last_trace.txt`. FlatCAM sources are left unchanged.

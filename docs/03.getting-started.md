# Getting started

Install FlatCAM, then start it. Packages and a from-source launch are in [Installation](./01.install.md).

FlatCAM keeps two kinds of settings. They are not in the project file.

## Where settings are stored

### Qt settings

Window layout, theme, language, and several font sizes are stored with Qt `QSettings` for organization `Open Source` and application `FlatCAM_EVO`.

| OS | Location |
|---|---|
| Windows | Registry key `HKEY_CURRENT_USER\Software\Open Source\FlatCAM_EVO` |
| macOS | `~/Library/Preferences/com.open-source.FlatCAM_EVO.plist` |
| Linux | `~/.config/Open Source/FlatCAM_EVO.conf` |

Keys written here include:

| Key | What it is |
|---|---|
| `font_size` | GUI Preferences → Font Size. Written only by **Apply and Restart** next to that field |
| `notebook_font_size` | App Settings → Notebook |
| `axis_font_size` | App Settings → Axis |
| `textbox_font_size` | App Settings → Textbox |
| `hud_font_size` | App Settings → HUD |
| `theme`, `appearance`, `dark_canvas` | Theme and canvas |
| `language` | Interface language |
| `layout`, `saved_gui_state`, `window_geometry` | Window and dock layout |

### Application data

Preferences values, the tool database, recent files, and the log live in a data folder.

| OS | Folder |
|---|---|
| Windows | `%APPDATA%\FlatCAM` (`C:\Users\<user>\AppData\Roaming\FlatCAM`) |
| Windows, portable mode | `config` next to the application, when `portable=True` in `config\configuration.txt` |
| macOS and Linux | `~/.FlatCAM` |

Files in that folder (the version suffix is the running FlatCAM version, currently `Unstable`):

| File | What it is |
|---|---|
| `current_defaults_<version>.FlatConfig` | Most Preferences values |
| `factory_defaults_<version>.FlatConfig` | Factory defaults copy |
| `tools_db_<version>.FlatDB` | Tool database |
| `recent.json`, `recent_projects.json` | Recent files and projects |
| `log.txt` | Application log |
| `preprocessors/` | Postprocessor scripts |
